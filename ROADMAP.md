# Roadmap

## ✅ Concluído (RC1 / RC2)

- Multi-tenant por slug + `RestaurantSessionContext`
- Stripe Connect Express + Split automático
- Platform Revenue Domain (monetização unificada)
- Loyalty transacional + Ledger append-only
- Order state machine + Kitchen Display
- Auditoria de segurança RC2-SEC-001 (OAuth bloqueado para parceiros/admins)

## 🟡 Curto prazo (soft launch → full launch, 3-5 dias úteis)

- Alertas proativos (Sentry / logs estruturados)
- Rate limit global em Edge Functions
- Reconciliação automática Stripe ↔ Ledger
- Responsividade mobile do painel admin
- Fluxo de refund via UI

## 🔵 Médio prazo

- App mobile do parceiro (React Native)
- Impressão térmica nativa
- WhatsApp Business API (envio automático de status)
- Marketplace de plugins/integrações

## 🟣 Longo prazo

- Multi-região / multi-moeda
- Marketplace público white-label
- IA operacional (previsão de demanda, sugestão de cardápio)
